# Viger

Viger is a full-stack game review application built as a take-home exercise. It uses a Next.js frontend, a Go REST API organized with hexagonal architecture, deterministic in-memory data, and WebSocket notifications for live review updates.

> The implementation is in progress. Complete build, run, test, architecture, and trade-off documentation will be added with the corresponding features.

## Planned quick start

```bash
docker compose up --build
```

The web application will be available at `http://localhost:3000` and the backend at `http://localhost:8080`.
